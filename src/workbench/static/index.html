Browser not starting? Setup & troubleshooting

The demo startup command does not start the browser. For LinkedIn, set WORKBENCH_MODE=live in .env, then run this in the project folder:

docker compose --profile live up --build -d --wait

Click Check connection, then Open browser here. The first browser image download can take a few minutes. If the viewer still refuses to connect, check docker compose --profile live ps and your configured BROWSER_PORT. On a remote machine, forward both the app and browser ports.

If a saved browser session is unavailable, restart only the browser with docker compose --profile live restart browser, then reset its connection below. This preserves cookies and never retries invitations.
